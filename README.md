# Проект "Получение данных о самолетах, находящихся в воздухе, с помощью открытого API https://opensky-network.org/ и загрузка полученных данных в БД PostgreSQL"

## Описание:
Данный проект позволяет:
* подключится с помощью открытого API к https://opensky-network.org/ и получить информацию о самолетах, находящихся в данный момент времени в воздухе
* создать структуру базы данных в PostgreSQL
* заполнить данными таблицы, созданные в БД PostgreSQL
* выполненять запросы к БД и возвращать результат

## Установка:
### 1. Клонируйте репозиторий: 

        https://github.com/basinanatali-star/Project_three_coursework_BD.git
### 2. Установите зависимости:

        pip install -r requirements.txt

## Использование:
Это учебный проект, поэтому можно использовать его как образец

### Модули проекта:
* Модуль module_1, содержащий функции для получения данных о самолетах в воздушном пространстве в момент времени
* Модуль module_2, содержащий класс для создания структуры БД 
* Модуль module_3, содержащий класс для заполнения БД данными из OpenSky
* Модуль module_4, содержащий класс для управления данными из БД PostgreSQL
* Модуль getting_a_token, содержащий функцию для получения токена доступа к OpenSky API
